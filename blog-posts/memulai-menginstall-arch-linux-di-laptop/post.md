# memulai menginstall arch linux di laptop

ternyata menginstall Arch linux tidak se sulit dulu dimana kita harus menginstall packagenya satu persatu, apalagi tanpa tanpilan visual/GUI. Hanya bermodalkan terminal, dan kita harus melakukan konfigurasi secara manual, yang dimana langkah langkahnya itu sangat banyak, walaupun arch wiki/dokumentasi arch linux sangat lengkap, tetapi itu membuat kita menghabiskan banyak waktu hanya untuk melakukan proses instalasi. Penginstalan seperti itu mungkin cocok bagi beberapa orang yang memang menginginkan sistem operasi yang benar-benar disusun sendiri dan sudah sangat memahami tentang sistem operasi linux terutama arch. Untuk orang yang tidak mau ribet dan hanya perlu menjalankan perintah seminimal mungkin. Sekarang file iso arch linux sudah menyertakan sebuah tools bernama archinstall, yang dimana saat dijalankan maka akan muncul aplikasi berjenis TUI, terminal user interface, yang lebih mudah dioperasikan dibandingkan hanya terminal cli.
dan konfigurasi system operasinya dilakukan secara otomatis, namun tetap hanya menginstall package yang dibutuhkan saja, dan terdapat juga pilihan desktop environment yang cukup banyak, dengan versi yang pasti terbaru, karena akan di download langsung dari repository arch linux yang rolling release.

## proses instalasi
### 1. download file iso archlinux
Download file iso archlinux dari web resminya di [archlinux.org](https://archlinux.org/download) scroll ke bawah sampai ketemu dengan kumpulan server dengan logo bendera berbagai negar, pilih yang paling dekat dengan kamu lokasinya. setelah itu pilih file yang berakhiran .iso dan pastikan download yang x86_64 dan bukan arm atau yang lainnya.
